# The Voice Design

Artboard. Paint. Press.

The Design studio in [The Voice](https://github.com/samrowland472-lang/TheVoice) — posters, covers, stories, and marks. Layouts with type, layers, and a real brush engine. Built to sit beside Speak and Animate.

## What it is

- Hub of templates (music, print, social, brand) plus a brand kit
- Canvas studio: shapes, type, pen, brushes, images, layers, inspector
- Command palette, present mode, smart guides, copy/paste, export PNG / JPG / SVG

Work stays in the browser (`localStorage`). No account required.

## Run

```bash
npm install
npm run dev
```

Then open the app in the preview. `npm run build` produces the production bundle.

## Stack

React 19, TanStack Start, Tailwind v4, Zustand, canvas renderer.
